## 🎮 How It Works

GitQuest is an autonomous developer RPG powered by Python and GitHub Actions.

Every day the kingdom decides whether to:

- ⚔️ Assign a quest
- 🎁 Discover treasure
- 🐛 Fight a bug
- 📚 Improve documentation
- 🧪 Strengthen testing
- 🌙 Take a rest day

The game automatically updates itself through GitHub Actions.
